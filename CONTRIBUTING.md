# Contributing

Useful contributions include reproducible calculation corrections, clearer units, tested worked examples and documentation improvements. Keep the project focused on selected material quantities.

For a bug, open the calculation issue form with minimal JSON, expected and actual results, toolkit/Node version and how the expected result was obtained. Remove names, addresses, private quotes and credentials. A structural design request is outside this toolkit's scope.

For a pull request, explain the trigger and resulting behavior. Add a meaningful test for a corrected calculation or newly supported input. Run `npm test`, update relevant docs and keep runtime dependencies at zero unless there is a clear need discussed first. Preserve existing license notices; only contribute material you are permitted to share.

Be respectful and specific. Promotional issues, unrelated link insertions and requests to hide advertising in examples do not help maintain this resource. No contribution response time is guaranteed.
